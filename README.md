# 🏠 Domio

> A modern Android application for managing your things, documents, reminders, and products.

## ✨ Features

- 📦 Asset management
- 📷 Barcode scanning
- 🔎 Product information lookup
- 📄 Document management
- ⏰ Reminders
- 💾 Local data storage
- 🌐 Backend API integration

## 🛠️ Tech Stack

### Android
- Kotlin
- Jetpack Compose
- CameraX
- ML Kit
- Room Database
- Coroutines

### Backend
- Node.js
- Express.js
- REST API

## 📱 Product Barcode Flow

1. Scan a product barcode
2. Detect barcode using the camera
3. Send barcode to the backend
4. Look up product information
5. Automatically fill product details
6. Review the information
7. Save the product to **Things**

## 🚀 Getting Started

### Clone the repository

git clone https://github.com/herish05/Domio.git

cd Domio

### Android

Open the project in Android Studio and build the application.

### Server

cd server

npm install

npm run dev
